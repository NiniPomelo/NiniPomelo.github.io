02 · FEATURED PROJECT

Brawl
& Turn

以 Meta Quest 為平台的虛實共域手勢互動系統，整合 MR／VR、角色戰鬥、空間 UI、多人體驗與 Same Room 定位測試。

PROTOTYPE / TESTING
ENGINEUnity / C#
DEVICEQuest 3 / 3S
MODEMR / VR
FOCUSMultiplayer XR

Overview

專題包含 BRAWL、QUALIFYING、Online 與 Same Room 等模式方向。玩家在頭戴裝置中選擇房間、地圖與角色，進入戰鬥後操作移動、跳躍、攻擊與防禦，最後由系統判定勝負。

Problem / Motivation

目標不只是讓功能可以執行，而是把 XR 操作、遊戲流程與多人狀態放進同一套體驗，處理玩家是否看得懂介面、不同裝置是否能看到一致狀態，以及共享空間定位是否合理。

01 · SETUP模式與房間

選擇模式、建立或加入房間，並確認玩家人數。

02 · SELECT地圖與角色

透過空間介面選擇地圖、角色與進入條件。

03 · PLAY倒數與戰鬥

整合移動、跳躍、攻擊、防禦、血量與動畫狀態。

04 · RESULT勝負結果

同步遊戲狀態，顯示 Victory 或 Defeat 結果。

Technology / Implementation

XR INTERACTION手部追蹤與空間 UI

使用 Meta Quest、OpenXR 與 Meta XR 處理手勢點擊，以及模式、地圖與角色等介面操作。

GAME SYSTEM角色與戰鬥流程

將移動、跳躍、攻防、血量、動畫、倒數與勝負判定放進同一套流程。

MULTIPLAYER房間與狀態同步

以 Unity Multiplayer Services、Netcode 與 Unity Transport 處理 Host／Member、位置、動作與遊戲狀態。

SHARED SPACESame Room 定位測試

針對 Anchor、玩家相對位置與不同裝置視角持續實作與調整，不將測試中的功能描述為完整穩定。

My Role / Integration

我的實作重點是把 XR 操作、角色控制、戰鬥、UI、多人體驗與場景定位整合在同一套遊戲流程中。各系統彼此影響，例如角色狀態需要同步到其他玩家，介面操作必須配合頭戴裝置與手勢，而 Same Room 模式還要比較不同裝置對實體空間的定位結果。

Challenges / Solutions

手勢誤觸

問題：手部移動可能意外觸發按鈕。
調整：測試觸發範圍、停留時間與介面距離，再修改點擊判定。

多人狀態差異

問題：角色、血量或比賽狀態可能不同步。
調整：檢查 Host／Member 訊息流程，分項測試位置、動作與結果。

Same Room 定位

問題：不同裝置可能出現位置偏移。
調整：持續比較 Anchor、玩家相對位置與裝置視角結果。

VR 新手操作

問題：第一次接觸的玩家可能看不懂提示或移動方向。
調整：重新安排面板位置、提示方式、操作順序與角色移動方向。

What I Learned

從單一功能實作進一步學習整合角色控制、戰鬥、UI 與多人同步，也在實機測試中理解空間定位、操作方式與玩家體驗之間的關係。成功連線只是第一步，完整體驗還需要讓玩家在正確時間看到一致狀態，並能自然理解操作。

02 · COURSE PROJECT

Unity
語音西洋棋

在程式設計（四）中，以 Unity 結合 OpenAI Whisper，讓玩家用說話移動棋子，並與簡單 AI 對戰。

COURSE PROJECT
ENGINEUnity
LANGUAGEC#
INPUTVoice
AISimple Opponent

Overview

語音不是附加功能，而是主要輸入方式。系統需要把語音辨識結果轉換成棋子與目標位置，再交由棋盤規則、回合狀態與簡單 AI 流程處理。

Implementation

VOICE語音輸入

使用 OpenAI Whisper 取得玩家指令。

PARSE指令解析

將辨識文字對應到棋子與棋盤位置。

RULES棋盤規則

讓移動結果配合西洋棋規則與回合流程。

AI FLOW簡單對戰

整合玩家操作與簡單 AI 的行動順序。

What I Learned

這項作品讓我練習把語音輸入、遊戲規則、物件控制與 AI 流程整合到同一個 Unity 專案，也看見辨識結果如何影響操作是否清楚、穩定。

02 · PROJECT DETAIL

數位漆扇
工坊

《數位漆扇工坊》是一個以傳統漆扇與水拓染為靈感的 p5.js 互動作品。使用者可以選色、拖曳滴管在水面滴入顏料，再用攪拌棒推動顏色流動，最後把扇面拖入水中完成拓印。

LIVE SKETCH
LIBRARYp5.js
TYPEInteractive Craft
FOCUSMarbling
OUTPUTFan Print
OPEN EDITOR FULL SCREEN

作品方向

我想把手作工藝裡「偶然、流動、不可完全控制」的美感轉譯成程式互動。顏料不是單純填色，而是以粒子、暈染和水面擾動的方式擴散；玩家的拖曳、攪拌和拓印動作，會共同決定最後扇面的圖案。
